## data that i collect
### goatcounter statistics
in order to have an idea about what sort of readership pages on this site are
getting, i use a fly.io-hosted instance of
[goatcounter](https://github.com/arp242/goatcounter/). it tracks page views
using javascript and/or a tracking pixel.

what's tracked:
- sessions
  - page visits, unique within an 8 hour window
- referrer
  - referer header, campaign parameters (utm_campaign, utm_source, ref)
- country
- language
  - supported languages from `Accept-Language`

disabling javascript and images for this site will effectively
remove you from any tracking should you care to do that.

[read more about goatcounter's privacy-friendly] approach
(https://www.goatcounter.com/help/privacy) bearing in mind that this site does
not use the cloud-hosted version of goatcounter.
